Connect

Settings go straight from this page to the receiver over USB. Nothing is uploaded.

Connect the receiver

  1. Plug the receiver into this computer’s USB-C port.
  2. Switch on the mics.
  3. Press Connect and pick “Wireless Microphone” in Chrome’s list.
Linux, ChromeOS: read & write
macOS, Windows: send only
Chrome then asks which HID device to connect
Wireless Microphonepick this

Full control on a Mac

Run the local bridge from the project folder. It asks for your password, and the receiver’s USB audio pauses while it runs.

npm run bridgewait for “captured”

No bridge on 127.0.0.1:47321

Receiver not in the list?

  • Unplug and re-plug it, or try another port. It must be a data cable.
  • Close the official app or other pages that might be using it.
  • Windows: check it shows as “Wireless Microphone” in Sound settings.

How it connects

The receiver gives this page two separate USB links.
